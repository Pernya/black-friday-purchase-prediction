# Данные
Положите исходные Black Friday CSV в эту папку: `train.csv` и `test.csv`.
В оригинальной работе имена были `train 2.csv` и `test_Vges7qu.csv`: можно переименовать копии либо передать пути через CLI.
Ожидаемые поля: `User_ID`, `Product_ID`, `Gender`, `Age`, `Occupation`, `City_Category`, `Stay_In_Current_City_Years`, `Marital_Status`, `Product_Category_1`, `Product_Category_2`, `Product_Category_3`. Цель `Purchase` присутствует только в train.
Исходные датасеты не входят в репозиторий. Используйте данные, доступные вам по условиям исходного учебного задания.
